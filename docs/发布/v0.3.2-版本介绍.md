# DdShell v0.3.2 发布

DdShell v0.3.2 是一个界面问题修复版本，基于 `v0.3.1..HEAD` 的实际提交整理。本次修复了终端多标签显示和文件传输状态两个影响日常使用的缺陷，无新增功能，建议所有用户升级。

## 亮点

### 修复多终端被强制平铺显示

连接两个及以上终端后，所有终端会同时铺开在同一屏内，看起来像是自动开启了分屏，而点击关闭分屏按钮又完全没有反应。

问题出在界面样式的优先级冲突：用于隐藏非当前终端的样式被主题样式覆盖，导致本应隐藏的终端始终可见。由于分屏状态实际从未开启，关闭分屏按钮自然也就无事可做。

现在默认只显示当前终端，是否分屏完全由分屏按钮和快捷键决定，且修复对全部 15 套主题一致生效。

### 修复文件传输完成后状态不归位

终端内置文件管理器在批量传输结束后，状态栏仍会长期显示「1 个传输中」，实际所有文件都已传完，需要关掉再重开抽屉才会恢复正常。

原因是最后一个任务收到完成通知后，又收到一条延迟到达的进度通知，把已完成的状态覆写回了「传输中」。现在任务进入完成状态后不再被进度通知回退，同时为终端文件管理器补上了与 SFTP 页面一致的状态轮询，即使个别通知丢失也能自动恢复。
